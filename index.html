Expected columns: FIRST NAME, LAST NAME (or a single NAME column; the last word is used as last name), USERNAME, COUNTRY (name, ISO or IOC code), GENDER (Boys/Girls, M/F), CATEGORY, HEAT, TIME. Rows are matched to existing athletes by username or full name; empty cells never erase existing data.
